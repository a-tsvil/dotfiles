# Charcoal City artwork

`charcoal-city/background.png` is a byte-for-byte copy of `stow/waybar/.config/waybar/wallpapers/amber-district-hl2-pixel.png`, the desktop wallpaper. It is reused without regeneration or image processing. The original pixel-art conversion prompt is recorded alongside that source image.

QML renders the wallpaper with smoothing and mipmaps disabled, then adds leaves and beacon lights. Tiny clean-sky samples from the same image cover the painted beacon glow; slim antenna stems and animated lights are drawn over those samples. The wallpaper PNG itself is unchanged.

Hyprlock uses the same PNG as a static background; SDDM adds the animations through the installed Astronaut login layout.
